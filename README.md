# 🏋️ AI Gym Coach

> **An AI-powered virtual fitness trainer that helps users perform exercises with proper form using real-time pose detection, automatic repetition counting, AI voice coaching, and instant feedback.**

---

## 🚀 Features

- 🤖 **AI Pose Detection** – Tracks body movements in real time.
- 🔢 **Automatic Rep Counter** – Counts repetitions accurately.
- ✅ **Form Correction** – Detects incorrect posture and provides instant feedback.
- 🎙️ **AI Voice Coach** – Gives real-time workout guidance and motivation.
- 📊 **Workout Tracking** – Tracks your workout performance.
- 📹 **Live Camera Support** – Uses your webcam for exercise analysis.
- ⚡ **Fast & Responsive UI** – Built with Streamlit for a smooth experience.
- 🧠 **LLM-Powered Coaching** – Personalized workout feedback using AI.

---

## ▶️ How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/AI-Gym-Coach.git
cd AI-Gym-Coach
```

---

### 2️⃣ Create a Virtual Environment (Optional)

**Windows**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**macOS/Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

---

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4️⃣ Add Your API Key

Create a `.env` file and add:

```env
GROQ_API_KEY=your_groq_api_key
```

---

### 5️⃣ Run the Application

```bash
streamlit run main.py
```

---

### 6️⃣ Open in Your Browser

```
http://localhost:8501
```
