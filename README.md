# 🏋️ AI Gym Coach

> **An AI-powered virtual fitness trainer that helps users perform exercises with proper form using real-time pose detection, automatic repetition counting, and instant feedback.**

## 🚀 Features

- 🤖 **AI Pose Detection** – Tracks body movements in real time.
- 🎯 **Automatic Rep Counter** – Counts exercise repetitions accurately.
- ✅ **Form Correction** – Detects incorrect posture and provides instant feedback.
- 🎙️ **Voice Guidance** – Delivers workout instructions and motivation.
- 📊 **Workout Tracking** – Monitors exercise performance and progress.
- 📹 **Live Camera Support** – Uses your webcam for exercise analysis.
- ⚡ **Responsive Interface** – Clean, fast, and easy-to-use design.

## 🛠️ Tech Stack

- 🐍 Python
- 🎈 Streamlit
- 🎥 OpenCV
- 🤖 MediaPipe
- 📊 NumPy
- 🎨 HTML, CSS & JavaScript

## 🎯 Supported Exercises

- 💪 Push-Ups
- 🏋️ Squats
- 🦵 Lunges
- 💪 Bicep Curls
- 🏃 Jumping Jacks
- 🧘 Plank
